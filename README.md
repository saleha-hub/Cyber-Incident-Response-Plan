# Cyber-Incident-Response-Plan
This task focused on designing a Cyber Incident Response Plan by simulating a ransomware attack scenario and documenting how an organization should respond to a cybersecurity incident using industry best practices.

Throughout this task, I worked on:

🔹 Designing a structured Incident Response Plan
🔹 Simulating a ransomware attack scenario
🔹 Applying the Incident Response Lifecycle (Preparation, Detection, Containment, Eradication, Recovery, and Lessons Learned)
🔹 Mapping attacker behavior using the MITRE ATT&CK Framework
🔹 Developing security recommendations and staff awareness practices
🔹 Understanding the importance of effective incident handling and business continuity

This experience enhanced my knowledge of incident response planning, ransomware mitigation, cybersecurity documentation, and security operations. Every task is helping me strengthen my practical cybersecurity skills and preparing me for real-world security challenges.
